# Leilão de Futebol - Pausa Global com Escalação Editável

## Atualização:
- Quando o anfitrião clica em **⏸️ Pausar Leilão**, o leilão para imediatamente para todos e abre um **modal gigante em formato de campo de futebol**.
- Nele, você pode alterar a formação, arrastar/escalar jogadores do banco de reservas e ver a **Média de Overall** do time em tempo real.
- Quando o anfitrião clica em **▶️ Retomar**, todas as suas alterações ficam salvas no seu time oficial.
